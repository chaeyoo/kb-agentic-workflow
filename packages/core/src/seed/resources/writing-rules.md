# 정책 작성 규칙

1. 정책은 섹션 단위로 쓴다. 섹션 하나는 한 가지 규칙 묶음만 다룬다.
2. 모든 문장은 "누가 / 언제 / 무엇을 할 수 있다·없다" 형태로 쓴다. "가급적", "원칙적으로" 같은 모호한 표현을 쓰지 않는다.
3. 연령은 항상 "만 N세 이상 / 미만"으로 적는다.
4. 예외가 있으면 같은 섹션 안에 "단," 으로 적는다. 다른 문서의 규칙과 겹치면 해당 섹션을 링크한다.
5. 변경할 때는 변경 이유와 근거(티켓, 결정 회의, 법령)를 반드시 남긴다.
6. 정책서는 사람이 승인한 변경안으로만 바뀐다. 에이전트는 변경안을 제안할 수 있지만 직접 수정할 수 없다.
