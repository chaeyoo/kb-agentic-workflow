## 장애 시

| 상황 | 대응 |
|---|---|
| API 가 느림/429 | 타임라인에 ⟳ 재시도가 보인다 → 오히려 설명 소재. 30초 넘으면 아래로 |
| API/네트워크 불가 | 서버를 `LLM_MODE=replay` 로 재시작 → reset → 같은 순서로 시연 (배지가 📼 REPLAY) |
| 에이전트가 다른 흐름으로 감 | 그대로 보여주고 설명 ("그래서 사람 승인이 있다"). 이어서 Internals 의 녹화 실행을 ▶ 다시 보기 |
| 리플레이가 "fixture 가 없습니다" | 순서가 달라졌다. reset 후 처음부터, 또는 화면 리플레이로 |
| 서버가 안 뜸 | `data/store.json` 삭제 후 재시작 (시드로 시작) |
