# 도메인 용어집

| 용어 | 뜻 |
|---|---|
| 수검자 | 검진을 실제로 받는 사람. 예약자와 다를 수 있다 |
| 예약자 | 앱에서 예약을 만든 회원 |
| 가족 연결 | 가족관계증명서로 가족 관계를 확인해 계정끼리 연결한 상태 |
| 법정대리인 | 친권자 또는 후견인. 앱에서는 가족 연결로 확인된 친권자·후견인 |
| 대리 예약 | 가족 연결된 가족의 검진을 대신 예약하는 것 |
| 노쇼 | 사전 취소 없이 검진에 오지 않은 것. 전날 취소도 노쇼 1회로 기록 |
| 민감 항목 | 유전자 검사, 정신건강 검사 결과. 의료진 상담 후 공개 |
| 정보성 알림 | 서비스 이용에 필요한 알림 (예약, 리마인드, 결과 등록 등) |
| 마케팅 알림 | 이벤트·프로모션 알림. 수신 동의 필요 |
| 휴면 계정 | 1년 동안 로그인하지 않아 전환된 계정 |
| 만 N세 | 생년월일 기준 만 나이. 정책서의 모든 연령은 만 나이다 |
| 미성년자 | 만 19세 미만 |
| 아동 | 만 14세 미만 |
| 청소년 | 이 앱의 정책서에서는 만 14세 이상 만 19세 미만 |
